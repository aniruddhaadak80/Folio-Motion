## ⚡ Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/ssubratkumar106-blip/Portfolio.git
cd Portfolio/Folio-Motion
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure Environment Variables (SMTP)
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```
Add your 16-character **Google App Password** (from [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)):
```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=ssubratkumar106@gmail.com
SMTP_PASS=your_16_character_app_password
CONTACT_RECEIVER_EMAIL=ssubratkumar106@gmail.com
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Build for Production
```bash
npm run build
npm run start
```
